# Read Rising Fantasy Chronicles Development Journal

Use this skill when you need to understand past features, milestones, databases, configuration directories, and current development states of Rising Fantasy Chronicles.

## Instructions
1. Locate and read the `development_journal.md` file in the root directory.
2. Review the session chronological logs (Milestones 1 to 10) to see what changes have been made to:
   - Authentication security and Google Sign-in flow.
   - UI styling, scanline removals, and mecha sprite outline erosion.
   - Forge equipment enhancement probabilities and safe/destruction levels.
   - Zone leveling maps and daily battle dungeons limits.
   - Android Capacitor configurations, Java social login plugins, and compilation commands.
   - NPC Base rosters (8 main NPCs) and Faction-exclusive crafting.
   - Custom character creation steps and name validation symbol exceptions.
3. Keep the journal updated whenever you perform major refactorings, security changes, or UI updates.
