FOLDER UNTUK GAMBAR / ASSET (.PNG, .JPG)
=========================================

Mbah, panjenengan saget upload file gambar .png teng mriki nggih!
Carane:
1. Nggih lewat File Explorer ing AI Studio sebelah kiri.
2. Klik kanan utawi seret (drag and drop) file .png panjenengan mlebet mriki.
3. Nek misale jeneng file-e `background.png`, mangke saget diakses langsung liwat path `/background.png` teng game.

Kulo sampun nambahake menu khusus "Custom Avatar & Background" teng pojok kiwo-ngandhap layar game, dadi panjenengan saget ngetik jeneng file utawi link URL gambar nggo ganti robot/background sesenenge ati!
